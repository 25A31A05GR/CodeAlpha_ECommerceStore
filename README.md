# CodeAlpha E-Commerce Store 🛍️

A full-stack e-commerce web application developed as part of the CodeAlpha Full Stack Development Internship.

## 🚀 Features

- Product listing
- Product details page
- Add to cart and remove from cart
- Automatic cart total calculation
- User registration
- User login
- SQLite database
- Checkout and order processing
- Order ID generation
- Order success page
- Responsive and user-friendly interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite

▶️ How to Run
1. Download the Project
Download the repository from GitHub using Code → Download ZIP.
2. Open the Project
Extract the ZIP file and open the project folder in VS Code.
3. Install Dependencies
Open the VS Code terminal and run:
npm install
4. Start the Server
Run:
node server.js
5. Open the Website
Open your browser and visit:
http://localhost:3000
